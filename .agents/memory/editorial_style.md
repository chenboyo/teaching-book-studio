# 教學寫作風格與認知設計指南 (Editorial Style & Voice Guide)

> **軌道定位**：本檔案屬於 **教學與編審記憶軌（Editorial Track）**。任何代理人在規劃或撰寫教材內容、簡報文字或講稿前，必須先閱讀並對齊本規範。

---

## 1. 目標學習者人物誌 (Target Learner Personas)
1. **自主學習者（Self-Paced Reader，使用教材閱讀模式）**
   - 情境：希望在安靜環境下徹底弄懂原理，不滿足於只有關鍵字的簡報，但遇到連續 300 字以上的抽象長文容易失去耐心。
   - 需求：白話比喻、看得到的圖解、隨時可點開的詞彙卡、做得到回饋的小練習。
2. **教室教師與講者（Presenter / Educator，使用簡報展示模式）**
   - 情境：站在投影幕或視訊分享前授課，需要畫面乾淨大字、讓聽眾一眼看懂結論，同時自己的螢幕旁要有講授提示與時間節奏控制。
   - 需求：一句話看懂每頁重點的「斷言標題」、視覺證據、獨立於畫面之外的「講者備忘錄（Speaker Notes）」與計時器。

---

## 2. 寫作語氣與個人化原則 (Personalization & Tone)
- **第一／第二人稱親切對話**：使用「你」與「我們」稱呼讀者，避免冰冷的第三人稱公文體（例如不寫「學習者應執行下列步驟」，改寫「我們先試著關閉一個干擾開關，看看大腦負擔怎麼下降」）。
- **先給生活直覺，再給正式定義**：遇到任何專業術語，一律先用一個日常比喻破冰（例如把工作記憶比喻成「書桌桌面大小」），再精準說出學理名稱與 `[[glossaryId]]` 標記。
- **誠實指出取捨（Trade-offs）**：每個方法都有適用邊界，教材應說明「什麼時候好用、什麼時候要小心」。

## 3. Richard Mayer 多媒體學習 12 原則實踐對照表

| 原則類別 | 本專案具體寫作與排版規則 |
| :--- | :--- |
| **極簡去噪 Coherence** | 禁止純裝飾性插畫、無意義表情圖堆砌或背景特效；每張圖與每個按鈕都必須直接服務當頁學習目標。 |
| **重點訊號 Signaling** | 用高對比色彩區分「好例子（綠）vs 反例（紅）vs 主結論（墨藍）」，在圖解中直接標示關鍵路徑與編號步驟。 |
| **講稿不重複 Redundancy** | 簡報頁面 **絕不複製整段教材散文**！簡報只放「1 句斷言 + 2~4 條精要關鍵詞 + 圖解」，完整口語說明放在 `speakerNotes`。 |
| **圖文空間緊鄰 Spatial Contiguity** | SVG 圖解上的元件說明標籤（Label）與指標線必須直接畫在元件旁邊，禁止把圖放左邊、圖例編號卻塞在頁尾。 |
| **分段節流 Segmenting** | 每個單元聚焦 1 個單一核心概念；複雜主題拆分為多頁漸進單元，並由學習者／講者自主推進節奏。 |
| **詞彙預習 Pre-training** | 在進入複雜原理單元前，先安排前置詞彙卡或於段落中用 `[[termId]]` 連結到即點即看詞彙卡，先熟悉名詞再看運作流程。 |
| **雙通道多媒體 Multimedia** | 概念說明盡可能同時具備「白話敘述」＋「結構化視覺圖解或互動模擬器」，忌純文字牆。 |

## 4. Michael Alley 斷言-視覺證據結構 & 密度預算 (Assertion-Evidence Budget)

每一個單元資料物件（Unit Object）必須嚴格遵守以下字數與密度預算（由 `pedagogyLinter.js` 自動把關）：

1. **`title`（目錄短標籤）**：4–14 字，方便側邊欄與簡報總覽網格快速掃描。
2. **`assertion`（核心斷言標題）**：**必須是一個「完整陳述句（主詞＋動詞＋結論）」**，建議 **12–28 個字**，不可只寫「第 3 章：認知負荷」這種名詞型空泛標題。
3. **`slidePoints`（簡報畫面重點）**：**2–4 條**，每條 **≤ 24 字**（純概念直覺關鍵句，絕不放長篇段落）。
4. **`bookProse`（教材深度散文）**：2–4 個短段落，總長度控制在 **120–380 字**之間，善用 `[[glossaryId]]` 標記關鍵詞彙。
5. **視覺證據（`visual` / `widgetId` / `comparison`）**：全書至少 **60% 以上單元**（示範教材為 100%）必須具備直接支持 `assertion` 的視覺圖解、互動元件或結構化對比卡。
6. **`speakerNotes`（講者備忘錄）**：提供 40–160 字的口語化授課提詞、提問互動話術與時間提醒（`durationSec`）。
7. **色彩語義（Semantic Color Discipline）**：
   - 溫潤紙本主軸：墨藍 `#1b365d` 代表主結構／核心主張；暖琥珀 `#b45309` 代表注意／認知負荷；森林綠 `#15803d` 代表推薦作法／通過；磚紅 `#b91c1c` 代表反例／過載警告。
